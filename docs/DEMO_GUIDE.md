# Demo and screenshot guide

Use `demo.py --launch`. Verify the fictional account names before recording. Close unrelated windows and hide notifications. Do not display your personal database, credentials, or local financial records.

## Suggested 2-3 minute demonstration

| Approximate time | Action | Explain |
|---|---|---|
| 0:00-0:20 | Open Dashboard | Purpose, Python desktop interface, fictional data. |
| 0:20-0:50 | Add a small expense to Demo Cash | A selected account is debited and the transaction appears in History. |
| 0:50-1:20 | Open Accounts and transfer 100 from Demo Bank to Demo Cash | Both balances change; total money and income/expense totals do not. |
| 1:20-1:45 | Show Budgets and Recurring | Current-month budget totals and the monthly occurrence rule. |
| 1:45-2:10 | Export PDF from History, then open the saved file | Complete paginated transaction report. Use a short destination path you are comfortable showing. |
| 2:10-2:40 | Briefly show the README | Exact-money storage, tests, known limitations, and AI assistance. |

Avoid claiming that all limitations have been solved. You do not need to expose login/reset secrets during the video.
