# Before publishing or submitting

- [ ] Run the fresh-environment smoke tests.
- [ ] Run the demo on Windows and check every menu.
- [ ] Capture real screenshots and record the short demo.
- [ ] Review the contribution/AI-assistance wording and keep only accurate statements.
- [ ] Search the files for personal information before upload.
- [ ] Do not upload any `.db`, `.db-*`, `.bak`, `.before_*`, `.env`, `.venv`, or `demo_data` contents.
- [ ] Check `git status --short` before committing. A `.gitignore` does not remove files already tracked by Git.
- [ ] Check any existing repository history for accidentally committed private data before making it public.
- [ ] Choose the repository visibility deliberately. This package does not publish anything.
- [ ] Decide on a source-code license before inviting reuse; no license grant is made by this package.
- [ ] Confirm the receiving institution permits optional portfolio links and follow its AI-disclosure rules.
- [ ] Test a repository download in a new folder using the README.

Suggested description: `Educational Python desktop finance prototype with SQLite, exact-money storage, account transfers, and reports. Developed with AI assistance.`
